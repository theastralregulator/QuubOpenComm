## Quick Starts

### Supabase CLI
To spin up local database configurations:
```bash
supabase start
supabase migration up
```

### Web Application
```bash
npm run dev
```

### Flutter Mobile App
```bash
cd apps/mobile
flutter pub get
flutter run
```
